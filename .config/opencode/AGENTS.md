# Среда: opencode в podman-контейнере

Ты выполняешься **в контейнере** `node:22-trixie` (Debian 13), root, `$HOME=/root`.

## Файловая система
- RW: только текущий проект (`$PWD` и его подкаталоги).
- RO: `~/.config/opencode/plugins`.
- Всё вне `$PWD` — слои образа; **правки вне проекта теряются** при перезапуске, не делай их.

## Жёсткие правила
1. Не выходи за пределы `$PWD` на запись. `/root`, `/etc`, `/usr/local`, `/home`, `/tmp` — не трогать.
2. В образе **только** Node 22, npm и `opencode`. Этого нет и **запускать нельзя**:
   `ripgrep`/`rg`, `gh`, `kubectl`, `helm`, `helmfile`, `k9s`, `uv`, `ansible`, `tmux`, `nvim`, `make`, `sudo`, `podman`, `docker`, `gpg`.
3. Не редактируй `opencode.json`, плагины, `Dockerfile`, `opencode.sh` — это хост-файлы, правки не подействуют в текущей сессии.
4. Если нужен недоступный инструмент — скажи пользователю и предложи альтернативу через встроенные инструменты (read/edit/grep/glob).
5. Секреты (`*_API_KEY`, `TELEGRAM_*`) в env — не печать и не логируй.
6. Сеть есть (`--network host`), systemd/dbus нет — службы не перезапускать.
